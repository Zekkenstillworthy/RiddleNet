What is Computer Network?

A computer network is a set of devices connected through links. A node can be computer, printer, or any other device capable of sending or receiving the data. The links connecting the nodes are known as communication channels.

Components of Computer Network

A computer network consists of the following key components:

  • Network Interface Card (NIC): Hardware that allows computers to connect to a network
  • Hub: A central device that connects multiple computers in a network
  • Switch: An intelligent device that connects multiple devices on a single network
  • Router: A device that forwards data packets between computer networks
  • Modem: A device that modulates and demodulates signals for transmission over telephone or cable lines
  • Cables and Connectors: Physical medium for data transmission between devices
Did You Know?

The first computer network was created in the late 1960s and was called ARPANET. It was developed by the Advanced Research Projects Agency (ARPA) of the United States Department of Defense. ARPANET is considered the predecessor of the modern Internet.
