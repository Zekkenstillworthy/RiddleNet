## How to Earn Badges

### 🥇 Cable Master (Legendary)
- **Option 1**: Score 100% in Cable Crimping
- **Option 2**: Complete Hard Mode with 75%+ score
- **Location**: Cable Crimping Simulation

### 🔧 Troubleshooting Pro (Epic)
- Complete troubleshooting with **zero mistakes**
- Unlock the "perfectionist" achievement
- **Location**: Troubleshoot Challenge

### 🏗️ Network Architect (Rare)
- Score 100+ in Network Topology
- **Location**: Link Up (Network Topology)

### 🔗 Topology Builder (Uncommon)
- Score 75+ in Network Topology
- **Location**: Link Up (Network Topology)

### 📚 OSI Expert (Rare)
- Score 100+ in OSI Model Challenge
- **Location**: OSI Model Simulation

### 📖 Layer Master (Uncommon)
- Score 75+ in OSI Model
- **Location**: OSI Model Simulation

## Visual Features

### Rarity System
Each badge has a rarity level with unique colors:
- **Legendary** (Gold) - Hardest to earn
- **Epic** (Purple) - Very challenging
- **Rare** (Blue/Violet) - Challenging
- **Uncommon** (Green/Indigo) - Achievable

### Interactive Effects
- **Hover**: Badges glow and lift up
- **Animation**: Badges appear with stagger effect
- **Glow**: Each badge has a colored aura

### Step 1: Complete a Challenge
Go to Cable Crimping and try to get 100%

## Mobile View

Badges automatically adjust for mobile devices:
- Responsive grid layout
- Touch-friendly hover effects
- Scales to fit any screen size

## Badge Information

Each badge card shows:
1. **Image/Icon** - Visual representation
2. **Badge Name** - Title of achievement
3. **Description** - How you earned it
4. **Rarity Label** - Difficulty level

## Tips

✅ **Complete challenges** to earn badges automatically  
✅ **Higher scores** unlock better badges  
✅ **Try hard modes** for legendary badges  
✅ **Zero mistakes** in troubleshooting = Epic badge  
✅ **Perfect scores** always earn the best badges  

## Questions?

- **Why don't I see my badge?** - Make sure you completed the challenge and returned to dashboard
- **How do I earn legendary badges?** - Get perfect scores (100%) or complete hard modes
- **Can I lose badges?** - No! Once earned, badges stay forever
- **Where are badges stored?** - Combination of database scores and browser storage
