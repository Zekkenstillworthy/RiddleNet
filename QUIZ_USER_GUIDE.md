# Quiz User Guide - How It Works

## 📚 Quiz Structure

The quiz is organized into **3 sets** of **5 questions each**:

- **Set 1**: Network Types & Basics
- **Set 2**: Network Devices  
- **Set 3**: OSI Model & Commands

**Total**: 15 questions

---

## 🎮 How to Take the Quiz

### Starting the Quiz

1. Navigate to **Challenges** page
2. Click on **Quiz Challenge** card
3. The quiz will automatically:
   - Check if you have saved progress
   - Show resume dialog if progress exists
   - Start fresh if no saved progress

### During Each Question

**You have:**
- ⏱️ **30 seconds** per question
- 🎯 **4 answer options** (A, B, C, D)
- 💡 **3 lifelines available:**
  - 50/50 (removes 2 wrong answers)
  - Skip (skip 2 questions)
  - Hint (see helpful hint for 3 questions)

**After answering:**
- ✅ See if you got it right or wrong
- 📖 Read the explanation
- ➡️ Click "Next Question" to continue

---

## 🎯 Set Completion

### After Every 5 Questions

You'll see a **Set Completion Screen** showing:

- ✨ Your score for that set (e.g., "4/5")
- 📊 Set accuracy percentage
- 🏆 Total score so far
- 📈 How many sets remain

### Your Choices:

**Option 1: Continue to Next Set**
- Click "Continue to Set X"
- Immediately start the next 5 questions
- No interruption to your flow

**Option 2: Save & Quit**
- Click "Save & Quit"
- Your progress is saved to database
- Return to Challenges page
- Come back anytime to resume

---

## 💾 Saving & Resuming

### Automatic Saving

Your progress is **automatically saved**:
- ✅ After each question you answer
- ✅ At each set completion screen
- ✅ When you click "Back" button
- ✅ When you click "Save & Quit"

### What Gets Saved?

- Current question number
- Which set you're on
- Your score
- Questions you've answered
- Lifelines you've used
- The exact order of questions (shuffle preserved)

### Resuming Later

When you return to the quiz:

1. **Resume Dialog Appears** showing:
   - Which set you're on (e.g., "Set 2/3")
   - Questions done in current set (e.g., "3/5")
   - Your current score

2. **Choose:**
   - **Resume Quiz**: Continue exactly where you left off
   - **Start Fresh**: Begin a new quiz (old progress erased)

## 🎓 Tips for Success

### Strategy
- ✅ **Take one set at a time** - No pressure to do all 15 questions
- ✅ **Use lifelines wisely** - Save them for tough questions
- ✅ **Read explanations** - Learn from each question
- ✅ **Take breaks** - Quit after a set if needed

### Lifeline Tips
- 💡 **50/50**: Best for when you're down to 2 choices
- ⏭️ **Skip**: Save for questions you're totally unsure about
- 🔦 **Hint**: Use early to guide your thinking

### Time Management
- ⏰ You have 30 seconds per question
- ⚡ Orange timer = 20 seconds left
- 🔴 Red timer = 10 seconds left
- 💨 Answer runs out of time = marked wrong

## 📊 Progress Tracking

### During Quiz
**Progress Display**: "Set 2/3 - Q3/5"
- First number = current set
- Second number = total sets (always 3)
- Third number = question within set
- Fourth number = questions per set (always 5)

### Set Completion Stats
- **Set Score**: Questions correct in this set
- **Set Accuracy**: Percentage for this set
- **Total Score**: Running total all questions
- **Sets Remaining**: How many sets left

### Final Results
- **Overall Score**: Total correct (e.g., "12/15")
- **Accuracy**: Overall percentage
- **Sets Completed**: How many sets done (e.g., "3/3")
- **Lifeline Usage**: How many of each used

## ❓ Frequently Asked Questions

**Q: Can I quit in the middle of a question?**
A: Yes! Click the "Back" button anytime. Your progress saves, but the current unanswered question won't be saved.

**Q: What happens if I run out of time?**
A: The question is marked incorrect, but you can still continue to the next question.

**Q: Can I retake the quiz?**
A: Yes! After completing (or from the resume dialog), click "Start Fresh" for a new attempt with reshuffled questions.

**Q: Will I lose progress if I close the browser?**
A: No! Progress is saved in the database, not your browser. You can even switch devices.

**Q: Can I skip an entire set?**
A: Not directly, but you can use your 2 skip lifelines to skip 2 questions per set if needed.

**Q: Do I have to complete all 3 sets?**
A: No! You can stop after any set. Your score will be based on questions you answered.

**Q: What if I want to change an answer?**
A: Once submitted, answers cannot be changed. This is why the timer gives you time to think!

**Q: Are the questions in the same order every time?**
A: No! Questions are shuffled each time you start fresh, but preserved when you resume.

## 🏆 Scoring & Completion

### Scoring Rules
- ✅ **Correct answer**: +1 point
- ❌ **Wrong answer**: 0 points
- ⏰ **Timeout**: 0 points
- ⏭️ **Skipped**: 0 points

### Completion Badge
To earn the quiz badge, you need:
- Complete all 3 sets (15 questions)
- Score 75% or higher (11+ correct)
- Badge automatically awarded on completion

- Your best score is tracked
- Compete with other students
