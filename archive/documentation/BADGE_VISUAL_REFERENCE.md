## 🎭 Animation States

### Entrance Animation
```
Frame 1 (0ms):    [ ]              (Invisible, scaled 0.8)
Frame 2 (100ms):  [▓]              (Fading in, scaling to 1.0)
Frame 3 (200ms):  [▓▓]             (80% opacity)
Frame 4 (300ms):  [███]            (Fully visible, normal scale)
                  ↓↓↓
           [BADGE DISPLAYED]
```

**Effect:** Staggered appearance with 100ms delay between each badge

### Hover Animation
```
Normal State:
┌─────────────┐
│   BADGE     │  ← Position Y: 0
│   [IMG]     │
└─────────────┘
     ║
     ║ [User hovers]
     ↓
Hover State:
     ▲ Position Y: -5px
┌─────────────┐
│   BADGE     │  ← Lifted
│   [IMG]     │  ← Glow intensified
└─────────────┘
   ▓▓▓▓▓▓▓▓▓
  Stronger Glow
```

**Effect:** Lift by 5px + increased glow + cursor changes to pointer

### Click/Focus State
```
┌─────────────┐
│   BADGE     │ ← Scale: 0.98 (pressed effect)
│   [IMG]     │ ← Slightly shrunk
└─────────────┘
```
