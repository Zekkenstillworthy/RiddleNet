┌─────────────────────────────────────────────────────────────────────┐
│ 🔄 HOW IT WORKS                                                     │
└─────────────────────────────────────────────────────────────────────┘

LOGIN:
1. User enters credentials
2. Check for existing active session
3. If exists → Terminate old session
4. Create new session with unique token
5. Store token in Flask session
6. User logged in

VALIDATION (Every Request):
1. Check if user is authenticated
2. Retrieve session token from Flask session
3. Validate token in database
4. Check if active and not expired
5. Update last_activity
6. If invalid → Log out and redirect

CONCURRENT LOGIN:
Device A: Gilbert logs in → Session A created
Device B: Gilbert logs in → Session A terminated, Session B created
Device A: Any request → Session A invalid → Logged out

      expiry_hours=48,  # ← Change this

┌─────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                  │
└─────────────────────────────────────────────────────────────────────┘

❌ Users getting logged out unexpectedly
   → Check session cookies are being sent
   → Verify session token is stored in Flask session
   → Check database migration completed

❌ Multiple sessions not terminated
   → Verify db.session.commit() is called
   → Check tables exist: user_sessions, instructor_sessions
   → Verify session tokens are unique

❌ Session expires too quickly
   → Check expiry_hours parameter
   → Verify last_activity is updated
   → Check system time is correct
