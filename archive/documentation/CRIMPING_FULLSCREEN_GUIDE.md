# Crimping Simulation - Fullscreen & Landscape Guide

## 🎮 How to Use Fullscreen Mode

### Automatic Fullscreen
1. Navigate to `http://127.0.0.1:5001/crimping-simulation`
2. Click anywhere on the page or tap the screen
3. The simulation will automatically enter fullscreen mode

### Manual Fullscreen Control
- **Fullscreen Button**: Look for the blue circular button in the top-right corner
- **Click to Toggle**: 
  - 🔲 Expand icon = Enter fullscreen
  - 🔳 Compress icon = Exit fullscreen
- **Keyboard Shortcut**: Press `Esc` to exit fullscreen

## 📱 Mobile Device Instructions

### For Best Experience
1. **Rotate Your Device** to landscape orientation
2. **Tap the Screen** to trigger fullscreen
3. **Use the Fullscreen Button** if needed

### If You See "Please Rotate Your Device"
- Simply rotate your phone/tablet to landscape mode
- The message will disappear automatically
- Game controls will become fully accessible

## 🖥️ Desktop Instructions

### Recommended Setup
1. Open the simulation in your browser
2. Click the fullscreen button (top-right)
3. Maximize your browser window if not already
4. Enjoy the full-screen crimping experience!

### Keyboard Controls
- `Esc` - Exit fullscreen mode
- `F5` - Refresh the simulation
- Click fullscreen button to re-enter

## 🔧 Troubleshooting

### Fullscreen Not Working?
1. **Check Browser Permissions**: Some browsers block fullscreen
2. **Try Manual Button**: Click the fullscreen toggle
3. **Refresh Page**: Press F5 and try again
4. **Update Browser**: Ensure you're using a modern browser

### Layout Issues?
1. **Rotate Device**: Ensure landscape orientation
2. **Refresh Page**: Force reload with Ctrl+F5
3. **Clear Cache**: Clear browser cache and reload
4. **Check Zoom**: Ensure browser zoom is at 100%

### Button Too Small?
- The simulation uses touch-friendly sizes (minimum 44px)
- Zoom in browser if needed (Ctrl/Cmd + Plus)
- Fullscreen mode provides more space
